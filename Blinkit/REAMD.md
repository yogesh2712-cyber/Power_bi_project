# BlinkIT Grocery Sales Dashboard 📊

## 📌 Project Overview
This project focuses on analyzing BlinkIT grocery sales data using **Power BI**.  
The dashboard provides insights into sales trends, customer behavior, product performance, and overall business metrics to support data-driven decision making.

---

## 📂 Dataset
**File:** BlinkIT.xlsx  

### Key Features:
- Customer purchase details
- Product categories
- Sales amount and order frequency
- Location-based analysis

---

## 📊 Dashboard Highlights
- Total Sales & Orders
- Category-wise Sales Performance
- Customer Purchase Trends
- Monthly / Seasonal Analysis
- Interactive Filters & Slicers

---

## 🛠 Tools & Technologies
- Power BI
- Microsoft Excel
- Data Cleaning & Transformation
- DAX (Basic Measures)

---

## 🚀 How to Use
1. Download the repository
2. Open `Seals.pbix` in Power BI Desktop
3. Ensure dataset path is correctly mapped
4. Refresh the data to view insights

---

## 🎯 Key Insights
- Identified top-performing product categories
- Observed customer purchasing patterns
- Seasonal sales trends highlighted
